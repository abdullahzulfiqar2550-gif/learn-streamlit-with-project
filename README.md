# 🚀 Learn Streamlit with Project

> **Learn Streamlit from scratch and build your first interactive application with confidence.**

This repository is designed for developers who prefer **learning by building**.

Instead of reading long documentation, you'll explore Streamlit through practical examples and then apply everything in a beginner-friendly mini project.

Whether you're a **Python Developer**, **Data Analyst**, **Data Scientist**, or **AI Engineer**, this repository provides a smooth introduction to building interactive web applications with Python.

---

## ✨ What's Inside?

📘 **Complete Streamlit Learning Notebook**

* Streamlit fundamentals
* Interactive widgets
* Layouts & containers
* Data display
* Charts & visualizations
* Best practices
* Practical examples

🚀 **Beginner Mini Project**

A simple Sales Dashboard built with Streamlit that demonstrates how to combine multiple components into a real application.

The project includes:

* 📊 Random e-commerce sales data generation
* 💰 Revenue, Profit & Orders
* 📈 Business metrics
* 🎨 Clean and interactive UI
* ⚡ Beginner-friendly code structure
